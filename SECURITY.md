# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in GazeAlert, please report it privately by emailing:
📧 **`blaga.ioan-catalin.24@stud.umfst.ro`**

Please include:
1. Description of the issue and potential impact
2. Steps to reproduce or proof-of-concept code
3. Affected versions and environment

We will respond promptly and provide updates as we investigate and deploy fixes.
